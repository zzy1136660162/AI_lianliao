# 项目总览

## 1. 产品组成

本项目包含两个对用户展示的产品空间：

- **链上辽宁·产业云城**：企业登录、企业码、企业库、产品库、在建项目、收藏、商机、供需、会员、数据发布和真人客服等企业业务工作台；
- **链辽AI**：AionUi/AionCore 提供的 AI 会话、Agent、工具、设置、定时任务和桌面能力。

两者运行在同一个 Electron 客户端中，但视觉、路由和状态边界必须清楚。企业工作台能够进入链辽AI；AI 工作区必须能返回企业工作台。企业明亮主题不能污染链辽AI原有主题。

## 3. 目标业务模块

整体开发范围按业务分为：

1. 桌面工具管理：客户端壳、AionCore、消息提醒、托盘、版本更新、诊断和开发调试；
2. 企业码：扫码登录、企业身份、企业库、产品库、企业码展示和企业数据管理；
3. 供需对接：供给、需求、推荐、询价、对接记录和发布；
4. 收藏与商机：统一收藏、在建项目潜在商机、跟进状态和项目解锁；
5. 在线互动：H5 客户咨询、H5 客服接待、Electron 客服接待和 Electron 普通用户咨询；
6. 用户会员体系：会员等级、积分、收费、权益、额度、订单和支付；
7. 企业数据发布：企业、产品、供给和需求的草稿、提交、审核、发布和下架；
8. 企业 AI 助手：基于真实企业、产品、项目和商机上下文生成分析和操作草稿；
9. 聚合消息中心：客服、商机、审核、会员、订单、更新和系统异常消息。

## 5. 关键术语

- **企业会话**：Electron 扫码成功后保存的 `openId` 和标准化企业用户上下文；
- **业务 ID**：Oracle 数字主键或历史负数 ID，跨 JS 边界一律使用规范十进制字符串，长度按具体接口 Schema 校验；
- **客服接待**：`roleId=19` 客服人员使用的会话队列和回复工作台；
- **在线咨询**：普通企业用户使用的单会话客户聊天页；
- **企业码**：企业身份、企业资料和移动端企业页面，不等同于单一二维码图片；
- **在建项目**：`OpportunityController` 提供的项目雷达、列表、详情和潜在采购信息；
- **链辽AI**：通用 AI 工作区；企业 AI 助手是其上层受控业务应用，不可直接执行未确认写操作。

## 6. 成功定义

项目完成不等于“页面都有入口”。完整交付必须同时满足：

- 页面使用真实服务端数据并覆盖 loading、empty、error、permission denied 和 success；
- Renderer、Preload、主进程和后端之间具有可校验契约；
- 写操作具有服务端身份、幂等、事务和并发保护；
- 角色、企业归属、会员权益和敏感字段由后端判定；
- 关键模块具有聚焦单元测试、跨页集成测试和真实环境验收；
- Windows 开发、构建、安装、更新、F12、AionCore 和本地 API 均保持可用；
- 三个仓库的已有业务不因企业桌面开发被覆盖或回退。
