## 4. P0：开发与后端基础

### DEV-01 开发模式 AionCore 自动解析

当前仓库已有可执行文件：

```text
resources/bundled-aioncore/win32-x64/aioncore.exe
```

当前工作区已经出现尚未提交的上下文注入和 `AIONUI_BACKEND_BIN` 解析代码，但尚未完成源码资源目录自动回退、生产隔离全套测试和错误界面分类。因此该项是“开发中”，还不能标记完成。现阶段通过临时修改 `PATH` 可以启动。

临时启动命令（工作目录必须是 `AionUi`）：

```powershell
cd E:\ZZY_PROJECT\AI_lianliao\AionUi
$backendDir = (Resolve-Path '.\resources\bundled-aioncore\win32-x64').Path
$env:Path = "$backendDir;$env:Path"
npm run start
```

长期解析优先级必须固定为：

```text
开发模式：AIONUI_BACKEND_BIN
       → process.resourcesPath
       → app.getAppPath()/resources/bundled-aioncore/<runtime>
       → PATH

正式安装版：process.resourcesPath
         → PATH
```

V1 运行时范围先限定为 Windows x64；其他平台缺少对应内置文件时必须给出“不支持该运行时”，不能回退为安装损坏提示。

待开发：

- [ ] 支持开发环境 `AIONUI_BACKEND_BIN` 显式覆盖。
- [ ] 自动检查 `app.getAppPath()/resources/bundled-aioncore/<runtime>`。
- [ ] 正式安装版保持现有安装目录解析，不读取源码目录或开发覆盖。
- [ ] 将非打包模式的 `resolve_binary` 失败分类为独立原因。
