## 1. 状态定义

| 状态       | 含义                                                               |
| ---------- | ------------------------------------------------------------------ |
| 已开发     | 主体源码、入口和聚焦测试已经存在                                   |
| 部分开发   | 有展示、旧接口或基础代码，但业务闭环不完整                         |
| 已设计     | 已确认书面规格，尚未进入功能实现                                   |
| 未开发     | 当前没有对应正式路由或主体源码                                     |
| 待真实验收 | 自动化和代码存在，但仍需真实微信、部署、Windows 安装或生产数据验证 |

## 7. 尚不明确、必须先只读调查的领域

以下领域不允许 AI 直接猜：

- 供给/需求收藏在 `J_CY_INTEREST.TYPE` 中的数字映射；
- 供需推荐、询价、发布、审核与对接记录的权威状态机和写入权限；
- 当前正式会员套餐、价格、发布额度和项目解锁权益；
- 积分余额、冻结、过期和扣减的权威账本；
- 支付渠道、创建订单接口、可信回调和退款状态；
- 企业、产品、供需发布审核的真实角色和表；
- 商机状态是否允许跳级或回退。

AI 应先查源码、Mapper、H5 和数据库元数据，再把“候选事实 + 证据路径 + 需要用户确认的选择”一起提出。
