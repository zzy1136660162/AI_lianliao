# 企业工作台 Ant Design 与 ECharts 全量迁移设计

## 1. 背景

“链上辽宁·产业云城”企业工作台当前使用 React 19、Arco Design 和自定义 CSS。企业页面已经形成独立的亮色主题、微软雅黑、15px 卡片圆角和轻阴影，但工作台仍存在以下体验与维护问题：

- 企业模块和后续计划采用的组件体系不一致，需要统一迁移到 Ant Design React。
- 当前项目数据分布主要用 `Statistic + Progress` 表达，缺少适合趋势和排行分析的图表。
- 工作台全局搜索结果交互可进一步统一为成熟的自动完成模式。
- 企业库、产品库和在建项目翻页后仍停留在页尾。
- 在建项目初始化 loading 卡片继承了通用状态组件的 560px 宽度限制，没有占满内容区。

本次迁移只覆盖企业登录与企业工作台。链辽AI、会话、设置和其他非企业页面继续使用原有组件体系。

## 2. 目标与非目标

### 2.1 目标

- 企业页面不再直接导入 `@arco-design/web-react`。
- 企业 CSS 不再包含 `.arco-*` 选择器。
- 企业登录、布局、搜索、筛选、表格、分页、详情、状态反馈全部使用 Ant Design React。
- 使用 ECharts 展示真实项目统计数据，并提供统一 React 生命周期封装。
- 保留企业工作台当前品牌视觉和独立滚动结构。
- 翻页或修改每页条数后，将业务主滚动区定位到对应列表表头。
- 统一 loading、empty、error 状态在各业务容器中的宽度与最小高度。

### 2.2 非目标

- 不迁移链辽AI、设置、会话和其他非企业页面。
- 不删除仓库级 Arco Design 依赖，因为非企业页面仍在使用。
- 不修改 cloud-service 接口、企业 API 请求协议或数据库。
- 不修改扫码登录、openid 明文传递、注册二维码和登录态恢复逻辑。
- 不修改企业、产品、项目等有符号整数 ID 的校验规则。
- 不在本阶段增加新的统计接口或虚构图表数据。

## 3. 组件体系与作用域

### 3.1 依赖

在桌面应用根包增加：

- `antd`
- `echarts`

ECharts 通过 `echarts/core` 按需注册图表、坐标系、提示框、图例和 Canvas 渲染器。不增加第三方 React ECharts 包，避免额外封装依赖。

### 3.2 企业 Provider

在企业路由根节点增加专用 `ConfigProvider`，配置简体中文、组件前缀和主题 token。主题保持：

- 字体：Microsoft YaHei、微软雅黑、Segoe UI、Arial。
- 主色：企业蓝。
- 页面背景：浅蓝白。
- 卡片背景：白色。
- 控件圆角：10px。
- 企业卡片圆角：继续由公共企业 CSS token 控制为 15px。
- 文字、边框和悬停颜色：映射现有 `--enterprise-*` 语义变量。

不导入 Ant Design 全局 reset，避免影响非企业页面。企业 CSS 只在 `.enterprise-shell` 和 `.enterprise-login` 下覆盖 Ant Design 组件样式。

### 3.3 组件替换矩阵

| 现有类别                         | 迁移目标                                 |
| -------------------------------- | ---------------------------------------- |
| Button                           | Ant Design `Button`                      |
| Form、Input、InputNumber、Select | Ant Design 同名组件                      |
| Table、Pagination                | Ant Design `Table`、`Pagination`         |
| Card、Tag、Statistic             | Ant Design 同名组件                      |
| Alert、Empty、Spin               | Ant Design 同名组件                      |
| 工作台搜索                       | Ant Design `AutoComplete + Input.Search` |
| Progress 模拟的数据分布          | ECharts 柱状图                           |

业务 hook、数据校验、路由、API 客户端和详情权限边界保持不变。

## 4. 搜索设计

工作台全局搜索继续调用现有 `useDashboardSearch`，保持 300ms 防抖、查询长度限制、并行查询和过期响应保护。

UI 改为 Ant Design 自动完成搜索：

- 企业、产品、项目按组展示。
- 每项保留主标题、辅助信息和业务图标。
- 支持方向键选择、Enter 跳转、Esc 关闭和清空关键词。
- 支持总请求失败、单组失败、加载中和无结果状态。
- 结果面板设置最大高度并独立滚动，不扩张整个企业页面。
- 导航路径继续使用经过编码的真实业务 ID。

企业库、产品库和在建项目筛选表单统一 Ant Design 控件高度、标签间距、清除按钮、焦点状态与按钮布局。筛选提交仍回到第一页，分页数据保留策略不变。

## 5. ECharts 设计

### 5.1 公共封装

新增 `EnterpriseChart`，负责：

- 创建并保存 ECharts 实例。
- option 更新时调用 `setOption`。
- 使用 `ResizeObserver` 响应容器变化。
- 组件卸载时取消观察并执行 `dispose`。
- 遵循 `prefers-reduced-motion`，必要时关闭动画。
- 提供明确的可访问名称；原始数值仍通过可读文本或隐藏表格提供。
- 数据为空时不创建空坐标轴，交由企业空状态展示。

### 5.2 图表内容

- 地区项目分布：横向柱状图，按项目数降序展示。
- 材料需求 TOP：横向柱状图，展示材料名称与需求数量。
- 一级分类对比：双系列柱状图，比较项目数量与材料数量。
- 工作台雷达区域：保留关键指标卡，将现有分布进度条替换为紧凑图表。

图表使用现有 `project.dashboard` 与 `project.drill` 的已校验数据。超长标签在坐标轴截断，Tooltip 展示完整名称和数值。桌面端并排、窄屏单列。

## 6. 列表翻页定位

企业库、产品库和在建项目分别持有列表顶部目标引用：

- 企业库：表格列标题区域。
- 产品库：产品卡片网格顶部。
- 在建项目：项目表格列标题区域。

用户切换页码或每页条数时：

1. 清理当前快速预览。
2. 提交分页状态变化。
3. 在下一动画帧中调用目标元素的 `scrollIntoView`。
4. 默认使用平滑滚动；系统减少动态效果时使用即时滚动。

目标位于 `.enterprise-shell__main` 内，因此只改变中间业务主区滚动位置，不影响侧栏和右侧企业助手。

筛选、重置和接口自动重试不触发该翻页滚动，避免非用户分页操作产生意外跳动。

## 7. 状态卡片布局

根因是通用 `.enterprise-page-state` 使用了 `width: min(560px, calc(100% - 32px))`，而在建项目初始状态直接把它作为 `.workspace` 的卡片，导致整张卡片被限制为 560px。

修复策略：

- 通用状态组件继续约束内部文案宽度，但不再用自身宽度限制业务卡片。
- 在建项目 workspace 中的 loading、empty、error 状态全部占满可用宽度。
- 企业库、产品库、项目详情和工作台雷达区保留现有全宽外层卡片。
- 状态类型切换时保持一致的最小高度，减少布局跳动。

## 8. 错误处理与兼容性

- Ant Design 迁移不改变现有错误码映射和安全文案。
- 图表初始化失败时保留可读的统计内容，不阻断列表与筛选。
- ResizeObserver 不可用时使用窗口 resize 事件作为受控降级。
- ECharts 不接收未经过现有 schema 与解析函数验证的接口数据。
- 图表 Tooltip 只使用文本值，不拼接不可信 HTML。
- 企业主题固定为亮色；应用处于深色主题时仍保持可读的亮色企业页面。

## 9. 实施顺序

1. 增加依赖与企业 Ant Design Provider。
2. 迁移通用状态、侧栏、头部、扫码登录和注册提示。
3. 迁移企业库、产品库和在建项目筛选、表格、卡片与分页。
4. 迁移企业、产品、项目详情和快速预览。
5. 重构工作台全局搜索。
6. 封装 ECharts 并替换项目统计视图。
7. 增加翻页定位与状态卡片全宽修复。
8. 删除企业模块残留 Arco 导入和 `.arco-*` 样式。

每个阶段必须保持应用可运行并独立提交，提交信息使用中文。

## 10. 测试与验收

采用测试驱动开发，先观察新增测试因缺少行为而失败，再实现最小变更。

自动化验收包括：

- 企业目录无 `@arco-design/web-react` 导入。
- 企业 CSS 无 `.arco-*` 选择器。
- Ant Design Provider 的语言、主题和作用域正确。
- 搜索防抖、分组、键盘操作、失败与清空行为保持正确。
- ECharts 注册、option 映射、resize、reduced-motion 与 dispose 行为正确。
- 空图表不创建无意义坐标轴。
- 三类列表翻页和修改每页条数后定位到正确目标。
- 非分页操作不触发列表滚动。
- loading、empty、error 状态卡片宽度一致。
- 扫码登录、注册二维码、openid、详情权限和有符号整数 ID 回归测试通过。
- 企业完整测试、两套 TypeScript 检查、格式与 lint 检查通过。

Electron 实机验收包括：

- 登录与企业工作台不存在 Arco/Ant 样式冲突。
- 图表在窗口缩放、助手展开/收起和窄屏下正确重排。
- 搜索结果面板不会拉长页面。
- 翻页只滚动业务主区。
- 在建项目初始化状态卡片占满内容区。
- 企业亮色主题在应用深色模式下仍保持正确对比度。

## 11. 完成条件

满足以下条件后本阶段完成：

- 企业登录和企业工作台全部使用 Ant Design React。
- 企业页面不存在 Arco 直接依赖和 Arco 专用 CSS。
- ECharts 图表使用真实已验证数据并完成生命周期处理。
- 搜索、分页定位和状态布局达到本设计验收标准。
- 所有新增与既有企业测试通过。
- 代码审查无未解决的 Critical 或 Important 问题。
