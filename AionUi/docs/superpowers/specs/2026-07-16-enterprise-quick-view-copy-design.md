# 企业列表快速预览去 ID 与文案优化设计

## 背景

企业库、产品库和在建项目列表在点击一行后，会在右侧打开快速预览。当前预览顶部展示“企业 / 1807”“产品 / 1234”“项目 / 5678”一类由业务 ID 截取出来的编号。该编号对普通用户没有决策价值，也容易让界面显得偏技术化。

本次采用方案 B：三类快速预览统一移除 ID，并优化标题、说明和底部主按钮文案。保持现有布局、接口、路由和详情页数据逻辑不变。

## 目标

- 企业、产品、项目快速预览均不再渲染任何实体 ID 或 ID 截断值。
- 用户一眼能分辨当前区域是“概览”，并理解进入完整档案后可以看到什么。
- 快速预览主按钮使用比列表“查看详情”更明确的实体档案文案。
- 三类组件结构、样式和多语言键保持一致，便于继续维护。
- 实体 ID 继续作为内部路由和数据请求标识，不改变现有功能。

## 非目标

- 不修改企业、产品、项目详情页的信息结构。
- 不修改列表列定义、筛选条件、分页或接口请求。
- 不隐藏 URL、IPC 或接口内部用于定位记录的实体 ID。
- 不在本次改造中重新设计整个右侧预览卡片。

## 组件设计

修改以下三个组件：

- `companies/CompanyQuickView.tsx`
- `products/ProductQuickView.tsx`
- `projects/ProjectQuickView.tsx`

统一结构为：

1. 右上角关闭按钮。
2. 实体类型概览标题。
3. 实体名称和已有状态/会员标识。
4. 关键事实信息。
5. 一句说明完整档案价值的提示语。
6. 打开完整档案的主按钮。

删除三个组件中的 `quickViewIndex` 节点以及 `slice(-4).padStart(...)` 展示逻辑。组件仍接收完整实体对象，并把完整 ID 交给既有 `onViewDetails` 回调；因此路由和详情查询不受影响。

## 中文文案

### 企业

- 区域标题及无障碍名称：`企业概览`
- 提示语：`查看完整企业档案，了解企业介绍、关联产品及可用联系方式。`
- 主按钮：`查看企业档案`

### 产品

- 区域标题及无障碍名称：`产品概览`
- 提示语：`查看完整产品档案，了解产品信息、所属企业及可用联系方式。`
- 主按钮：`查看产品档案`

### 项目

- 区域标题及无障碍名称：`项目概览`
- 提示语：`查看完整项目档案，了解建设单位、采购需求及联系方式开放状态。`
- 主按钮：`查看项目档案`

列表操作列继续使用现有“查看详情”文案。快速预览按钮新增独立的 `quickView.action` 键，避免改变列表按钮。

## 多语言策略

- 从企业、产品和项目的 `quickView` 对象中删除不再使用的 `index` 键。
- 为三个 `quickView` 对象新增 `action` 键。
- 更新 `label`、`title` 和 `hint`。
- `zh-CN` 使用上述中文文案。
- 其余九个语言文件沿用当前企业模块的英文文案策略，使用清晰一致的英文概览与档案文案，避免只翻译局部内容。
- 修改全部十个 locale 后重新生成 `i18n-keys.d.ts`，并运行完整 i18n 一致性校验。

## 样式设计

- 删除三个 CSS Module 中废弃的 `.quickViewIndex` 样式。
- 快速预览标题区域保留足够的右侧空间，避免与绝对定位的关闭按钮重叠。
- 不改变侧栏宽度、卡片背景、内容滚动和响应式断点。
- 桌面宽度和窄窗口下都不得产生新的横向溢出。

## 数据与错误处理

本次不增加数据请求，也不改变错误处理。缺失字段仍使用现有 `missing` 文案；受限联系方式仍由详情页现有权限逻辑控制。唯一的数据边界变化是实体 ID 不再进入可见 DOM。

## 测试与验收

### 自动化测试

- 在企业、产品和项目快速预览 DOM 测试中使用可识别的测试 ID，并断言快速预览中没有该 ID 或截断值。
- 断言三个快速预览分别渲染新的 `quickView.title`、`quickView.hint` 和 `quickView.action`。
- 断言列表操作列仍使用既有 `actions.viewDetails`。
- 运行 i18n 类型生成与 `scripts/check-i18n.js`。
- 运行企业模块相关测试、TypeScript、格式和 Lint 检查。

### 运行时验收

- 在企业库、产品库、在建项目中分别点击一条记录，确认侧栏不显示任何 ID。
- 确认三个主按钮仍能进入正确详情路由。
- 在桌面和窄窗口下确认标题不与关闭按钮重叠，页面无横向溢出。
- 确认浏览器控制台无新增错误。

## 成功标准

三个列表的右侧快速预览均只呈现用户可理解的业务信息，不显示技术 ID；文案统一、动作明确，原有详情导航和权限逻辑保持正常。
