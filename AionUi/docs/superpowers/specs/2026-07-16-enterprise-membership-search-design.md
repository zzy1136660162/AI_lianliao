# 企业会员标识与工作台搜索栏统一设计

## 背景

企业工作台已经迁移到 Ant Design，但首页统一搜索框只调整了输入框主体高度，
`Input.Search` 的按钮仍使用组件默认尺寸，因此输入框与搜索按钮的上下边界、边框和圆角没有对齐。

企业相关页面目前直接显示“`{{level}} 级会员`”，这与手机端 H5 企业码通过
`comLevel` 展示实名认证、普通会员、VIP 会员、星级会员和旗舰店图片的业务表达不一致。
企业库列表还展示了用户不需要的“更新时间”列。

## 目标

1. 修复工作台统一搜索框与搜索按钮不对齐的问题。
2. 将企业会员等级的文案、图标和降级行为封装为可复用能力。
3. 在工作台当前身份、企业库列表、会员筛选、快速预览和企业详情中统一使用该能力。
4. 从企业库列表移除“更新时间”列，并同步调整表格最小滚动宽度。
5. 为本次涉及的公共映射、组件边界、接口参数转换和异常降级补充准确注释。

## 非目标

- 不修改 `E:\ZZY_PROJECT\lianshang_liaoning` 的 H5 代码。
- 不新增或修改后端接口。
- 不改变登录态、企业库查询条件、分页逻辑或企业详情权限。
- 不对企业模块以外的历史注释进行无边界重写。
- 不推送 GitHub；实现继续直接提交到本地 `master`。

## 方案选择

采用“共享等级映射 + 统一 React 组件 + 本地等级资源”方案。

- 等级判断只有一个数据源，避免不同页面各自维护条件分支。
- 展示组件同时处理图片、业务文案和未知值降级。
- 等级图片随桌面应用打包，不依赖 H5 部署地址或运行时网络。
- 筛选项复用同一映射的文字和图片，但保留现有查询值，确保接口行为不变。

没有采用页面内联判断，因为会重复 H5 的复杂分支并造成长期漂移；也没有采用运行时
会员配置接口，因为现有 H5 图标是静态资源，当前没有可依赖的完整动态图标协议。

## 组件与模块设计

### 会员等级映射

新增一个企业会员等级模块，负责把接口返回的 `companyLevel/comLevel` 转成稳定的展示模型：

```ts
type CompanyMembershipPresentation = {
  label: string;
  icon: string | null;
  kind: 'verified' | 'ordinary' | 'vip' | 'star' | 'flagship' | 'unknown';
};
```

映射规则与 H5 当前有效资源保持一致：

| 接口值 | 业务名称 | 图标 |
| --- | --- | --- |
| `1` | 实名认证 | `sm.png` |
| `1.1` | 普通会员 | `l1.1 copy.png` |
| `1.2`、`2`、`3` | VIP 会员 | `VIP_level.png` |
| `4` | 4 星会员 | `l4 copy.png` |
| `5` | 5 星会员 | `l5 copy.png` |
| `6` | 旗舰店 | `l6 copy.png` |
| 未提供或非有限数字 | 暂未分级 | 不展示图片 |
| 其他有限数值（例如 `3.1`、`7`） | `会员等级 {{level}}` | 不展示图片 |

对于 H5 代码尝试访问但资源目录中不存在的 `l7` 至 `l10`，桌面端不生成损坏图片；
保留可理解的文字降级，以便继续接受后端已有数值。

### 统一会员组件

新增 `CompanyMembershipBadge`：

- 输入只接受可选数值等级，以及紧凑尺寸等纯展示属性。
- 内部调用共享映射，不允许调用方自行拼接“级会员”。
- 有图标时使用本地图片，并提供与业务名称一致的 `alt`/可访问名称；不重复渲染图片中已有的可见文字。
- 无图标时显示统一文字标签。
- 支持表格、下拉选项、身份卡、快速预览和详情页所需的紧凑布局。
- 组件样式位于企业公共样式范围内，避免页面重复定义图片高度和对齐方式。

### 页面接入范围

以下位置全部改用统一组件或统一映射：

1. 企业工作台“当前身份”卡片。
2. 企业库会员等级表格列。
3. 企业库会员等级筛选下拉项。
4. 企业快速预览。
5. 企业详情页顶部标签和基本信息字段。

企业库“更新时间”列将从列定义中移除。由于列宽减少，表格横向滚动最小宽度也同步下调，
避免保留无意义空白或过早出现横向滚动条。

## 搜索栏修复

根因是现有样式只覆盖 `.ll-ant-input-affix-wrapper` 的最小高度，没有覆盖
`Input.Search` 的组合容器和 `.ll-ant-input-search-button`。

修复将统一以下部分：

- 输入组合容器高度和伸缩规则。
- 输入框主体与搜索按钮高度。
- 左侧圆角、右侧圆角及相邻边框合并。
- 聚焦状态的边框和阴影，不改变当前自动完成、键盘导航及请求逻辑。
- 窄屏下保持满宽，不产生水平溢出。

## 数据流与接口保持不变

企业库继续由渲染进程发起：

```ts
client.request({ operation: 'company.list', payload: query });
```

Electron 主进程继续把它转换为：

```text
POST {enterpriseBaseUrl}/cloud-api/CompanyController/getQiYeMaCompanyList
```

开发环境 `enterpriseBaseUrl` 保持 `http://127.0.0.1:12580/`。`openId`、`fromCompanyId`
和 `fromUserId` 仍从已验证登录上下文注入，页面不直接维护这些身份字段。

本次只改变会员等级的展示，不改变 `comLevel` 筛选值，也不改变接口响应规范化逻辑。

## 测试与验收

先添加失败测试，再实现生产代码。

### 自动化测试

- 等级映射覆盖 `1`、`1.1`、`1.2`、`2`、`3`、`4`、`5`、`6`、未知值和空值。
- 统一组件验证正确图片、业务文案、无障碍名称和未知值降级。
- 工作台、企业列表、快速预览和详情页不再出现“`1.2 级会员`”类技术文案。
- 企业列表不再渲染“更新时间”列。
- 企业表格滚动宽度与新列集合一致。
- 搜索栏样式测试验证输入框、组合容器和按钮共用统一高度。
- 保留并运行现有企业工作台单元测试与集成测试。

### 运行验收

- 在 Electron 开发模式打开企业工作台，确认搜索输入框和按钮上下边界完全对齐。
- 在企业工作台、企业库、快速预览和详情页核对同一等级展示一致。
- 验证企业库筛选、分页、详情跳转和自动完成搜索行为未回归。
- 在窄窗口验证无水平溢出，会员图片不被拉伸。
- 检查开发者工具控制台无新增错误。

## 失败与降级策略

- 会员等级为空或异常时展示“暂未分级”，页面继续可用。
- 后端返回未配置图片的等级时展示文字，不请求不存在的资源。
- 本地图片打包失败会由构建检查发现，不在运行时回退到不受控远程地址。
- 搜索请求失败仍沿用现有分组错误和重试逻辑，本次样式调整不介入请求状态。
