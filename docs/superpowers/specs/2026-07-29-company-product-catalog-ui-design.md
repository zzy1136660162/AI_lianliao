# 企业库与产品库 UI 优化设计

## 1. 背景

链上辽宁·产业云城桌面工作台已经具备企业列表、产品列表、快速预览和详情页。现有页面可以完成基本查询，但企业与产品页面的视觉语言、信息密度、详情结构和公共组件仍不够统一。

本次设计只优化 `LianLiaoAIPC` 桌面端展示层，不修改 Cloud API、接口字段、会员等级规则、联系方式权限规则或收藏业务逻辑。

## 2. 已确认的设计方向

用户已确认以下选择：

- 使用平衡型产品策略：企业库偏业务效率，产品库偏图片展示，详情页保持统一。
- 使用“明亮政企云城”视觉风格。
- 列表采用紧凑型信息密度。
- 详情页采用“概览 + 固定侧栏”结构。
- 公共样式和公共组件需要封装，避免企业与产品页面重复维护。

未采用的方向：

- 不采用整页深色产业图谱风格。
- 不采用藏蓝、暖白、金色为主的招商展厅风格。
- 不将企业列表改为纯卡片画廊。
- 不使用隐藏大量内容的多标签页详情结构。
- 不使用需要长距离滚动的纯企业名片长页。

## 3. 设计目标

### 3.1 业务目标

- 提高企业列表的筛选、比较和详情进入效率。
- 提高产品列表的图片辨识度，同时保持较高的同屏信息量。
- 让企业详情和产品详情拥有一致的信息层级和交互预期。
- 保持现有接口、会员、收藏和联系方式权限逻辑不变。

### 3.2 体验目标

- 常规桌面宽度下，企业列表可快速扫描，产品列表优先显示四列卡片。
- 列表与详情不出现横向溢出，内容区域可以独立正常滚动。
- 翻页后自动回到列表表头。
- 从详情返回列表时保留筛选条件、页码和滚动位置。
- 加载、空数据、错误和图片失败状态均使用稳定、不跳动的页面结构。

## 4. 视觉系统

### 4.1 品牌与色彩

- 用户可见品牌保持“链上辽宁·产业云城 AI桌面平台”。
- 页面底色使用极浅蓝白色，主要内容容器使用纯白色。
- 主操作色使用现有品牌蓝。
- 青色只用于状态、数据和少量辅助强调。
- 不在普通业务卡片中堆叠复杂渐变。
- 警告、错误、成功和会员等级继续使用各自的语义色。

### 4.2 字体

- 桌面企业工作台统一使用微软雅黑优先字体栈。
- 页面主标题使用明确的粗体层级。
- 正文、表格和说明文字不得使用过细字重。
- 表格辅助说明和卡片描述通过字号、颜色区分层级，不依赖降低到难以阅读的透明度。

### 4.3 圆角、边框与阴影

- 主要业务卡片统一使用 `15px` 圆角。
- 输入框和按钮使用小于主卡片的统一圆角。
- 卡片使用浅蓝灰边框和轻量阴影。
- 悬停状态可以轻微提升阴影，但不进行大幅位移或缩放。
- 当前选中项使用浅蓝背景和清晰焦点状态，不使用过重描边。

### 4.4 间距

- 页面级、卡片级和字段级间距分别沉淀为公共变量。
- 紧凑型只压缩无意义留白，不压缩点击区域和文字行高。
- 筛选区、列表区、分页区保持稳定的垂直节奏。

## 5. 企业库列表

### 5.1 页面结构

企业列表页由以下区域组成：

1. 页面标题、说明和结果摘要。
2. 紧凑筛选卡片。
3. 企业数据表格。
4. 分页区域。
5. 按需打开的右侧快速预览。

### 5.2 筛选区

- 企业名称、所属行业、省份、城市、区县和会员等级保持当前业务字段。
- 查询与重置按钮和输入控件底部对齐。
- 常用筛选条件首屏展示，未来新增的低频条件进入“更多筛选”，避免无限横向堆叠。
- 查询期间按钮显示明确加载状态。
- 重置操作恢复默认条件并回到第一页。

### 5.3 表格

建议列顺序：

1. 企业名称。
2. 行业。
3. 所在地区。
4. 会员等级。
5. 主营摘要。
6. 操作。

行为要求：

- 企业名称单元格展示主名称和一行辅助说明。
- 主营摘要限制合理行数，不能挤压操作列。
- 会员等级继续使用移动端一致的名称和图标。
- 表头在列表内容滚动时保持可见。
- 单击行选择企业并打开快速预览。
- 双击行或点击“查看详情”进入完整详情页。
- 键盘焦点、回车进入详情和可访问标签需要保留。
- 翻页完成后自动滚动到表头位置。

### 5.4 快速预览

- 快速预览位于右侧，不改变整个应用壳宽度。
- 展示企业名称、会员等级、行业、地区、主营摘要和主要操作。
- 不显示企业数据库 ID。
- 底部提供“查看完整详情”主按钮。
- 关闭预览后列表宽度恢复，不保留不可见占位。

## 6. 产品库列表

### 6.1 页面结构

产品列表页由以下区域组成：

1. 页面标题、说明和结果摘要。
2. 紧凑筛选卡片。
3. 产品卡片网格。
4. 分页区域。
5. 按需打开的右侧快速预览。

### 6.2 产品卡片

- 常规桌面宽度优先四列。
- 中等宽度自动降为三列，小宽度自动降为两列。
- 图片使用统一比例和固定容器，避免卡片高度不一致。
- 图片加载失败或地址无效时使用统一品牌占位图。
- 卡片展示产品名称、所属企业、产品分类、所在地区和会员标识。
- 描述最多展示两行。
- 底部操作固定在卡片底部，提供“快速预览”和“查看详情”。
- 产品卡片可以保持轻微悬停反馈，但不使用影响排版的位移动画。

### 6.3 快速预览

- 展示产品主图、名称、所属企业、分类、地区和产品摘要。
- 所属企业名称可以进入企业详情。
- 不显示产品数据库 ID。
- 底部提供“查看完整详情”主按钮。

## 7. 企业详情页

### 7.1 顶部名片

顶部名片区展示：

- 企业 Logo 或品牌占位图。
- 企业名称和简称。
- 行业与所在地区。
- 会员等级。
- 认证状态。

当前桌面端没有企业收藏写接口，本次只保留接口已有的收藏状态兼容字段，不新增不可用的收藏按钮。

### 7.2 主内容区

主内容区依次展示：

1. 企业概况。
2. 主营业务。
3. 企业介绍。
4. 代表产品。

企业概况使用紧凑信息网格展示法定代表人、企业类型、成立时间、统一社会信用代码、行业和会员等级。缺失字段统一显示友好的缺失文案，不显示 `null`、`undefined` 或空白布局。

代表产品使用可点击产品卡片，进入对应产品详情。

### 7.3 右侧固定栏

右侧栏展示：

- 联系人。
- 联系电话。
- 详细地址。
- 会员解锁操作。
- 企业近期动态或关联业务摘要。

未解锁时：

- 前端保留真实字段所在位置。
- 文本使用现有公共高斯模糊样式。
- 显示简短的“尚未解锁联系方式”提示。
- 不显示数据库 ID 或内部权限字段。

解锁成功后：

- 在原位置显示真实内容。
- 不强制跳转或刷新整个页面。
- 联系方式状态与现有公共权限组件保持一致。

## 8. 产品详情页

### 8.1 顶部名片

顶部展示：

- 产品主图或品牌占位图。
- 产品名称。
- 产品分类。
- 所属企业。
- 所在地区。
- 接口已有时展示会员等级或认证标识。

### 8.2 主内容区

主内容按接口已有字段依次展示：

1. 产品简介。
2. 所属企业。
3. 行业与地区。
4. 地址等有效业务信息。

当前产品详情契约只包含产品名称、所属企业、图片、简介、行业、地区、地址和联系方式等字段。本次不创建没有数据来源的“产品参数”“适用范围”或“详细说明”空栏目；未来接口增加对应字段后再扩展公共详情卡片。空字段不渲染无意义占位，不显示内部字段名。

### 8.3 右侧固定栏

右侧栏展示：

- 所属企业名片。
- 联系人。
- 联系电话。
- 联系方式解锁操作。
- 进入企业详情入口。

联系方式锁定、解锁和会员升级逻辑与企业详情使用相同公共组件。

## 9. 导航与状态保持

- 列表筛选条件、页码、当前选中项和滚动位置保存在路由状态或列表页面状态中。
- 从详情页点击返回时恢复原列表状态。
- 用户直接从侧边菜单重新进入列表时使用列表默认状态。
- 快速预览和完整详情使用明确不同的路由或状态，不通过数据库 ID 文案提示用户。

## 10. 公共组件

建议在现有企业工作台公共组件目录中封装以下职责，具体名称可以根据现有目录结构微调：

- `EnterpriseCatalogShell`：列表页标题、说明、筛选区和内容区骨架。
- `CatalogFilterCard`：筛选控件、查询、重置和更多筛选布局。
- `CatalogPagination`：分页与翻页后表头滚动。
- `CatalogQuickViewPanel`：快速预览容器、关闭、焦点和底部操作。
- `DetailHeroCard`：企业和产品详情顶部名片。
- `DetailSectionCard`：详情内容卡片标题和正文结构。
- `StickyContactCard`：联系方式、模糊状态、解锁和会员升级入口。

继续复用：

- 会员等级徽章。
- 接口已有的收藏状态兼容字段。
- 联系方式权限验证和解锁逻辑。
- 页面加载、空数据和错误状态。
- Ant Design 基础组件。

## 11. 样式组织

- 公共圆角、阴影、边框、间距和页面底色沉淀为企业工作台公共样式变量。
- 企业列表和产品列表只维护业务特有布局，不重复定义公共卡片外观。
- Ant Design 全局主题调整放在既有公共覆盖文件中。
- 仅当前页面需要的复杂样式保留在对应 CSS Module。
- 不新增未经国际化处理的用户可见文本。

## 12. 加载、错误和边界状态

### 12.1 加载

- 列表加载骨架占满列表可用宽度。
- 详情加载骨架保持顶部、主内容和侧栏结构，避免加载完成后大幅跳动。

### 12.2 空数据

- 空列表展示当前筛选无结果说明和重置筛选入口。
- 企业无代表产品时展示简洁空状态，不渲染空白卡片。
- 图片缺失使用品牌占位，不显示浏览器破图。

### 12.3 错误

- 列表请求失败保留筛选条件并提供重试。
- 详情请求失败使用占满内容宽度的错误卡片。
- 联系方式接口失败只影响联系方式区域，不阻断公开详情。
- 所有错误文案通过国际化配置管理。

## 13. 响应式规则

- 宽屏桌面：详情主内容和固定侧栏并排，产品四列。
- 中等桌面：缩小侧栏宽度，产品三列。
- 小窗口：详情侧栏进入主内容下方，产品两列。
- 所有断点下禁止横向溢出。
- 固定侧栏只在可用高度和宽度足够时启用粘性定位。

## 14. 测试与验证

### 14.1 企业列表

- 筛选、重置、分页和翻页后滚动。
- 表格选中、快速预览、双击和详情跳转。
- 缺失字段、长名称和长主营摘要。

### 14.2 产品列表

- 响应式列数。
- 图片正常、缺失和加载失败。
- 快速预览、产品详情和企业详情跳转。
- 长名称和两行描述截断。

### 14.3 详情页

- 加载、成功、无数据和请求失败。
- 联系方式锁定、解锁、权限不足和接口失败。
- 接口已有收藏状态字段的兼容渲染，不新增收藏写操作。
- 从详情返回列表后的筛选、页码和滚动恢复。

### 14.4 工程验证

- 运行受影响模块的 Vitest 测试。
- 运行 TypeScript 类型检查。
- 运行 Oxlint 和 Oxfmt 检查。
- 运行国际化类型生成与检查。
- 运行桌面端生产构建。

## 15. 非目标

- 不修改 Cloud API。
- 不新增数据库表或字段。
- 不改变会员等级、收费、联系方式获取或收藏规则。
- 不重新设计工作台侧边栏和 AI 功能区。
- 不引入新的 UI 组件库。
- 不在本次范围内修改移动端 H5 页面。

## 16. 验收标准

- 企业库与产品库呈现统一的明亮蓝白视觉语言。
- 企业表格使用紧凑密度，并能稳定打开快速预览和详情。
- 产品列表在常规桌面宽度下优先四列，图片和卡片高度一致。
- 企业与产品详情采用统一的顶部名片、主内容和右侧联系方式结构。
- 详情页不显示数据库 ID。
- 联系方式锁定时使用高斯模糊，解锁后在原位置显示真实信息。
- 翻页后滚动到表头，从详情返回后恢复列表状态。
- 加载、空数据、图片失败和接口错误不会造成布局溢出或大幅跳动。
- 现有接口、会员权限、收藏和联系方式业务行为保持兼容。
