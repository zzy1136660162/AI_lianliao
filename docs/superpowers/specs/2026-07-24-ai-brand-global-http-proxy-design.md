# 链上辽宁·产业云城AI助手品牌与全局 HTTP 代理设计

## 1. 背景

链辽桌面端当前存在两项需要统一处理的问题：

1. AI 工作区仍显示“链辽AI”和历史 Aion 图标，与“链上辽宁·产业云城”企业工作台的品牌标识不一致。
2. Electron 普通 HTTP 请求、Node.js WebSocket、AICore 及其启动的 Agent/MCP 使用不同的网络栈。开发环境连接本机地址时正常，但生产环境需要 HTTP 代理时，部分网络请求不会自动继承 Electron 或操作系统代理。

本次改造只涉及 `LianLiaoAIPC`。不修改 cloud-service、数据库、AICore 协议、Electron App ID、安装器标识及用户数据目录。

## 2. 目标

- AI 工作区用户可见标题统一为“链上辽宁·产业云城AI助手”。
- AI 工作区使用与企业工作台一致的品牌 Logo。
- 在“设置 → 系统”中增加用户可维护的手动 HTTP 代理配置。
- 同一份代理配置覆盖 Electron HTTP、生产 WebSocket、AICore、Agent、MCP 和模型请求。
- 本机环回地址始终直连，避免代理破坏 Electron 与 AICore 的本地通信。
- 代理配置在下次应用启动、AICore 启动前生效。

## 3. 非目标

- 第一版不支持需要用户名和密码的代理。
- 不实现 PAC、SOCKS、按域名配置多个代理或企业集中下发。
- 不修改操作系统的全局代理设置。
- 不将代理配置同步到 cloud-service 或用户账号。
- 不改变“链上辽宁·产业云城 AI桌面平台”这一操作系统级产品名称。

## 4. 品牌展示

### 4.1 标题

AI 工作区使用独立的标题常量：

```text
链上辽宁·产业云城AI助手
```

该名称用于 AI 工作区侧栏和移动端 AI 标题。原有短品牌常量“链辽AI”继续用于登录、浏览器通知和既有功能文案，避免修改一个界面标题时意外改变其他产品边界。操作系统通知、安装器、窗口元数据继续使用“链上辽宁·产业云城 AI桌面平台”。

### 4.2 Logo

AI 工作区侧栏不再渲染历史内联 Aion SVG，直接复用企业工作台已有资源：

```text
packages/desktop/src/renderer/assets/logos/brand/app-mark.png
```

Logo 保持等比例缩放，不增加黑色底板。标题区域需要允许长标题安全收缩，不能挤压窗口控制或导致侧栏横向滚动。

## 5. 代理配置模型

### 5.1 持久化字段

在 Electron 本地配置中新增：

```ts
type ManualHttpProxyConfig = {
  enabled: boolean;
  url: string;
};
```

配置键使用 `system.httpProxy`。该配置必须存放在 Electron 主进程启动阶段即可读取的本地 `ProcessConfig` 中，不能只存入 AICore 的客户端设置接口，否则会产生“AICore 启动前无法读取代理”的循环依赖。

### 5.2 地址校验

- 只接受完整的 `http://` 或 `https://` URL。
- 必须包含主机名和有效端口。
- 拒绝 URL 中的用户名、密码、查询参数、片段和非根路径。
- 保存前删除首尾空白并标准化 URL。
- 关闭开关时保留最后一次填写的地址，便于再次启用，但运行时不应用。

第一版示例：

```text
http://127.0.0.1:7897
```

### 5.3 绕过规则

以下目标始终直连：

- `localhost`
- `127.0.0.0/8`（包含 `127.0.0.1`、`127.1` 等 IPv4 环回地址）
- `::1`
- Electron 当前启动的 AICore 本地端口

环境变量中的 `NO_PROXY`/`no_proxy` 至少包含上述环回地址和 `127.0.0.0/8` CIDR。

## 6. 组件与职责

### 6.1 主进程代理配置服务

新增一个边界清晰的主进程服务，负责：

- 读取和验证本地代理配置。
- 将配置写入 `ProcessConfig`。
- 生成 Electron session 代理规则。
- 生成 Node.js WebSocket 使用的 `HttpsProxyAgent`。
- 生成 AICore/Agent/MCP 继承的代理环境变量。
- 提供脱敏后的当前状态，不在日志中输出潜在凭据。

业务 API、通知模块和客服模块不得各自解析代理字符串。

### 6.2 IPC

在 application IPC 范围增加：

- 读取代理配置。
- 保存代理配置。

保存操作由主进程完成校验和持久化。渲染进程不直接读写本地文件。

### 6.3 系统设置界面

“设置 → 系统”增加独立的“网络代理”区域：

- “启用手动 HTTP 代理”开关。
- 代理地址输入框。
- 示例和生效范围说明。
- 保存按钮。
- 格式校验错误。

保存成功后提示用户重启应用。应用重启前不承诺 AICore、Agent 和 MCP 已切换代理，避免展示部分生效的误导状态。

### 6.4 Electron HTTP

应用启动后根据配置调用 Electron session 的代理 API：

- 启用时使用固定代理。
- 禁用时恢复系统代理。
- 本地环回地址进入 bypass 规则。

由 Electron session 发出的 `net.fetch`、下载和 Chromium 网络请求继承该配置。

### 6.5 Node.js WebSocket

桌面通知和客服 WebSocket 当前使用 Node.js `ws`，不会自动继承 Electron session 代理。创建生产 `wss://` 连接时：

- 启用手动代理：传入 `HttpsProxyAgent`。
- 禁用手动代理：保持现有直连行为。
- 本地 `ws://127.0.0.1` 始终直连。

代理切换以后通过应用重启重建所有 WebSocket，避免同一进程中残留旧连接。

### 6.6 AICore、Agent 和 MCP

AICore 启动前，将启用的代理写入其子进程环境：

```text
HTTP_PROXY
HTTPS_PROXY
ALL_PROXY
http_proxy
https_proxy
all_proxy
NO_PROXY
no_proxy
```

禁用手动代理时，不注入应用保存的代理值，并保留操作系统原有环境变量。AICore 启动的 Agent、MCP 和其他子进程继续继承这些环境变量。

应用内手动代理优先于启动 Electron 时已有的代理环境变量；关闭手动代理后恢复启动时的环境基线，不永久修改父进程或操作系统环境。

## 7. 启动与保存流程

### 7.1 启动

1. 初始化 Electron 本地存储。
2. 读取并验证 `system.httpProxy`。
3. 构造本次运行的代理环境。
4. 启动 AICore，使其继承代理环境。
5. Electron ready 后配置默认 session。
6. 创建企业 HTTP 客户端、桌面通知 WebSocket 和客服 WebSocket。

配置文件损坏或字段不合法时，记录不含代理地址的诊断信息，并按“未启用手动代理”启动，不能阻断客户端进入界面。

### 7.2 保存

1. 用户编辑配置并点击保存。
2. 主进程验证并标准化地址。
3. 原子写入本地配置。
4. 返回保存结果。
5. 界面提示重启。
6. 用户确认后走现有应用重启逻辑；开发模式提示手动重启。

## 8. 错误处理与日志

- URL 格式错误：不保存，界面显示明确原因。
- 代理地址合法但不可达：允许保存；具体网络连接按现有重试机制失败，避免保存时依赖某一个外部测试地址。
- WebSocket 连接错误：日志记录模块、目标主机、错误码和重连次数，不记录 ticket、openid 或完整带参数 URL。
- AICore 启动失败：继续使用现有启动失败诊断，不把“配置了代理”等同于“代理一定是失败原因”。
- 代理关闭或配置读取失败：恢复系统代理/直连，不遗留上一次手动代理。

## 9. 测试与验收

### 9.1 自动测试

- HTTP/HTTPS 地址标准化与非法输入拒绝。
- 用户名密码、路径、查询参数和无端口地址拒绝。
- 启用、禁用和本地 bypass 环境变量生成。
- 启动环境基线恢复，避免污染全局测试环境。
- WebSocket 在生产 WSS 下使用代理 agent、本地 WS 下直连。
- IPC 只返回可克隆的纯数据并正确保存配置。
- 系统设置初始化、错误提示和保存后重启提示。

### 9.2 手工验收

1. AI 侧栏显示“链上辽宁·产业云城AI助手”及工作台 Logo。
2. 配置 `http://127.0.0.1:7897` 并重启。
3. 生产 API 请求成功。
4. 桌面通知 WebSocket 建立连接并收到实时消息。
5. 客服 WebSocket 能建立连接。
6. AICore 的模型、Agent 和 MCP 外部请求能够通过代理访问。
7. `http://127.0.0.1:<AICore端口>` 始终直连。
8. 关闭手动代理并重启后恢复系统代理/直连。

## 10. 兼容性

- 不改动 `aioncore.exe`、REST 路径、WebSocket 事件和 MCP ID。
- 不改动 Electron `appId=com.lianliao.app`。
- 不改动旧用户数据目录和迁移规则。
- 旧版本没有 `system.httpProxy` 时等价于未启用手动代理。
- WebUI 浏览器模式不展示或不应用 Electron 专属代理设置。
