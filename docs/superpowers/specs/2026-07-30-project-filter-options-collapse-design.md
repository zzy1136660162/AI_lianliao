# 在建项目数据库筛选与机会总览折叠设计

## 目标

将“在建项目”页面中的省份、城市、一级品类、二级品类、材料简称和材料名称改为来自项目分析数据库的下拉选项，并按父级条件级联加载；将“项目机会总览”改为默认折叠的风琴面板，让用户进入页面后优先看到项目列表。

## 数据来源与约束

- 筛选项使用 `TMP_HPINFO_YCL_AI` 与 `TMP_HPINFO_YCL_AI_REL` 的最新有效 `RUN_ID` 数据，不创建需要人工维护的静态字典表。
- 新增 `OpportunityController/getAiMaterialFilterOptions`，请求维度固定为：
  `province`、`city`、`categoryL1`、`categoryL2`、`materialShortName`、`materialName`。
- 服务端使用枚举白名单和 MyBatis `<choose>` 选择列，禁止将客户端维度直接拼接进 SQL。
- 返回项统一为 `{ value, label, projectCount }`，按项目数倒序、名称正序排列。
- 单次返回默认 500 条，最大 1000 条；无效维度直接返回参数错误。
- 选项接口失败时仅显示下拉加载失败，不得阻断项目列表、项目总览或已输入关键字。

## 级联规则

### 地区链

1. 初始加载省份。
2. 选择省份后加载城市；清空原城市值。
3. 省份或城市变化后，重新加载当前地区范围内的一级品类，并清空所有材料分类子级。

### 材料链

1. 一级品类选定后加载二级品类。
2. 二级品类选定后加载材料简称。
3. 材料简称选定后加载材料名称。
4. 任一父级变化时，立即清空所有失效子级，子级未满足父级条件时保持禁用。

## 前端交互

- 项目关键词保留自由输入；投资额保留数字输入。
- 数据库字段使用 Ant Design `Select`，支持清空、搜索、加载状态和无结果状态。
- 每次级联请求使用最新请求标识防止旧响应覆盖新选择。
- 重置筛选时清空值并重新加载省份和一级品类。

## 项目机会总览

- 使用受控 `Collapse` 风琴面板。
- 初始 `activeKey` 为空，即默认折叠。
- 折叠标题保留“项目机会总览”和数据更新时间。
- 展开后渲染指标卡、地区热度、重点采购材料和分类对比图。
- 折叠状态只在当前页面生命周期内保存，不写数据库或本地存储。

## 风险验证

- 非法维度与超过上限的请求不会形成动态 SQL 注入面。
- 父级变化后旧子级值和旧请求响应不能残留。
- 筛选选项接口异常时项目列表仍正常展示。
- 总览默认折叠，用户可展开并看到原有指标和图表。
- cloud-api Mapper XML 可解析，cloud-api 可编译；Electron 契约、DOM 测试、类型检查、i18n 校验和生产构建通过。
